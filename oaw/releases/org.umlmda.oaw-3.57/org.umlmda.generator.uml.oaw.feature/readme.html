Overview

This feature provides the functionality for UMLMDA to work in combination with oAW.

Changes

Version 3.0.4 / 05.03.2008

New Features

  • Support for delegates for none generatable code.
  • Improved javax.jmi.reflect implementation
  • Support to change the decimal type mapping with the global oAW variable decimalMapping

Changes

Bugfixes

  • Fixed date handling in parameters (typemapping can be set in the global variables dateMapping, dateTimeMapping and timestampMapping, default is set to java.util.Date.
  • Fixed delegate handling in classes with multiple baseclasses.
